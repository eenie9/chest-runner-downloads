## Getting started

1. Install Chest Runner on Windows 10 or newer (x64).
2. Enable Fortnite replay recording for the modes you play.
3. Keep Chest Runner open or in its system tray while you play. Completed supported replay files are imported automatically.

Setup checks the Microsoft .NET 10 Desktop Runtime and WebView2. The .NET runtime is bundled; WebView2 may need internet access if missing.

Choose **Open in browser** from the app menu to view the same local data in your browser. Keep the desktop app running for this companion view.

Deleting recorded games removes the app's saved records and prevents immediate automatic reimport. Original Fortnite replay files are kept. Uninstalling also preserves saved match history.

## Preview limitations

Replay support depends on Fortnite version and playlist. Updates to Fortnite may require an app/parser update. Counts reflect openings the replay can link to a player; missing information stays unknown.

This preview installer is unsigned. Windows may display an unknown-publisher or reputation warning. Keep Windows security protections enabled and review release details before installing.
